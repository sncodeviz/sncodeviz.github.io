Hotel Booking Database & ETL Pipeline

Database and ETL project transforming a denormalized operational data store containing more than 40,000 booking records into a normalized third-normal-form relational database.

SQL ServerSSISVisual Studio3NFETL

The question

How can hotel booking data be structured and validated to support reliable operational reporting and business analysis?

Analytical approach

  • Designed a normalized 3NF hotel-booking database in SQL Server.
  • Developed an SSIS and SQL ETL pipeline to extract, cleanse, transform, and load booking data into normalized dimension and transaction tables.
  • Created primary and foreign key relationships, lookup tables, and master data tables.
  • Validated the database using SQL queries and business-focused analysis.

Findings & outcomes

  • Source operational data store contained more than 40,000 booking records.
  • Relational design supported analysis of booking volume, cancellations, customer patterns, room demand, and market segments.

Limitations & interpretation

This project focuses on database design, ETL, validation, and analytical readiness rather than a published interactive dashboard.
