Diabetes Prediction Project

Machine-learning project using clinical and demographic data to explore diabetes-risk classification, with attention to class imbalance, model comparison, and interpretability.

Pythonscikit-learnSMOTEClassificationModel Evaluation

The question

How can classification models be compared when predicting diabetes risk in an imbalanced dataset?

Analytical approach

  • Developed a Python machine-learning pipeline using clinical and demographic features.
  • Applied feature engineering and SMOTE to address class imbalance during model development.
  • Compared Logistic Regression, Decision Tree, and Random Forest models.
  • Selected a Decision Tree based on balanced predictive performance and interpretability.

Findings & outcomes

  • Emphasizes model comparison, class-imbalance handling, and interpretability rather than relying on accuracy alone.
  • Report and code are available in the project repository.

Limitations & interpretation

This is an educational analytics project, not a clinical diagnostic tool. Predictions should not be used for medical decisions.
